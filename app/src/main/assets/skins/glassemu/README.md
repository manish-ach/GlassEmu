# GlassEmu skin

Bundled portrait and landscape layouts for GlassEmu. Light mode uses the white artwork; dark mode applies a purple tint at runtime.

Portrait adapted from Ant’s [Ultimate DSi Skins (For Delta)](https://deltastyles.com/skins/599-ultimate-dsi-skins-for-delta). Landscape adapted from the Candybar DS layout by Dwichotomy, with modified artwork and controls. Original creator metadata is retained in the source JSON files.

The app reads these extracted assets directly; the original `.deltaskin` archives are not required.
